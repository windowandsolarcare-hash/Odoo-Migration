**CONFIRMED unbounded accumulator #1 — `routers/owner/swr.py`:** module-level `_CACHE` and `_LASTGOOD` dicts, **never evicted, no cap/LRU**. `bust()`/`bust_prefix()` only pop `_CACHE`, NEVER `_LASTGOOD`. Real leak, though likely only PART of the ~340MB — more accumulators still to find (scheduler/prewarm baseline + other module-globals next). **First surgical fix (Lead-approved 2026-11-05, build+stage for byte-QC, ship as an independent increment):** bound `_CACHE`/`_LASTGOOD` with a **count-based LRU** (leaf helper, low blast radius, removes no working logic).
