The saunders-render-app repo has **`3_Documentation/ENDPOINT_MAP.md`** — a canonical map of EVERY HTTP route, auto-generated by an AST sweep of `main.py` + every `routers/**/*.py` (first generated 2026-09-03 by Auditor).

It contains: (1) a **shadow rule** explainer; (2) a **SHADOWED/DEAD routes** table (~98 colliding full-paths — for each, the LIVE handler that wins vs the DEAD twin that never runs; `dashboard.py` is included first under `/owner` so it shadows big chunks of payments.py / timeclock.py / shift_review.py / quotes.py / hemet.py / cron.py / planner.py / activities.py / stale_sos.py / submitted_jobs.py / calendar.py / po.py); (3) a **Full route table** grouped by prefix (root / /book / /owner ~707 routes / /tech / /cheryl / /printing) with columns: **ST (LIVE or DEAD), METHOD, /full/path, file:line, handler, what it does (docstring first line), auth.**

**Why:** a fresh session can find the right endpoint, confirm it's the LIVE one (not a silently-dead shadowed twin), see which file:line serves it, and read what it does — WITHOUT reading router code. Big efficiency win + it prevents the shadow trap (editing/calling a dead twin has zero effect). This is especially valuable for the Operator session (execute-via-endpoints).

**How to apply:** make it the FIRST stop for "which endpoint does X / is it live / what file serves it / what auth." It is a SNAPSHOT — routes added after the last regen won't be in it, so verify very-recent additions against live code.

**REGEN (fixed 2026-09-04 by Auditor):** the AST generator is now COMMITTED at **`3_Documentation/gen_endpoint_map.py`** (the prior one was never committed — that's why the map drifted). One-command refresh: `python 3_Documentation/gen_endpoint_map.py <repo_root>` after `git reset --hard origin/main`; it reads main.py's include order directly (no list to maintain) and rewrites ENDPOINT_MAP.md in place. **Freshness process:** the SHIPPING session regenerates on push (push-checklist step, regen > hand-patch); Auditor re-runs on a cadence as backstop. NOT a deploy/boot hook (deploy risk). Map is current as of 2026-09-04 (787 routes / 690 live / 97 dead).
