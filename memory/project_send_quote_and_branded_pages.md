**SEND QUOTE** (DJ feature, LIVE 2026-10-26 main `06ff3af1`; §15 Lead+Audit dual-GREEN, auto-deploy, no DJ nod — the SEND itself stays DJ-tapped/review-first). From **v2_quote.html** after Save, a **✉️ Send Quote to Customer** button (in #success) → review sheet (editable/roundable price) → the customer gets a **branded quote_view page showing ONLY the service label + the $ amount** (never pane counts / difficulty / line breakdown — DJ: "do not pass along too much information"). By email or text.

- **Routes (NEW):** `GET /owner/api/job/quote_view` (dashboard.py — PUBLIC, token-gated FAIL-CLOSED, in authz `PUBLIC_EXACT`; sig = `_quote_sig(so_id)` = HMAC(key, `'quote:%d'`)[:16], key `SESSION_SECRET or ODOO_API_KEY or 'wsc'`, distinct `'quote:'` namespace vs invoice/photo). `POST /owner/api/job/send_quote` (brain.py — sibling of `job_send_invoice`; MIRRORS it: `messaging.send(kind='quote')` → STOP/DNC + quiet-hours HOLD; review-first `send:false` preview; email via mail.mail; `_log_quote_sent` writes the timeline View link). `_render_quote_doc` (dashboard.py) reuses the invoice page's CSS SHELL verbatim (service+$ row only). **Fast-follows (Lead green-lit, NOT done):** shared `_branded_doc_shell()` extraction (resolve the CSS dup); multi-service quote rounding.
- **INVARIANT (the money-safety core): DJ-confirmed $ == `amount_total` == what customer sees.** `_apply_quote_override(so_id, amt)` (brain.py) rewrites ONLY the windows line `price_unit` in place (the `[Render Quote Tool]` breakdown NOTE line + sibling service lines untouched → breakdown preserved), guarded by `_has_posted_invoice` (never rewrite a posted bill), bounded `0 < amt <= 100000`.
- **SIBLING-LINE guard (Audit MEDIUM, fixed before promote):** a quote SO CAN carry an add-on priced line (e.g. Pressure Wash — see `_replace_quote_line` Bruce-Karp note). Then `amount_total = windows + add-ons`, so a windows-only override would diverge from what the customer sees. Fix: `_quote_other_priced_lines(so_id)` (brain.py; **FAIL-SAFE: returns True on any read error** → disables override, never over-quotes) → `_apply_quote_override` REFUSES + writes nothing if a sibling exists; preview returns `can_override` + the TRUE `amount_total`; client prefills from the true total (NOT `calcTotal`), and when `can_override` is false the price field goes **read-only** and send posts **without** `amount_override` → server sends `amount_total`. `confirm()` shows the exact number (cents-exact when read-only, rounded only when editable). So single-line quotes keep full rounding; add-on quotes send the exact true total DJ reviewed.

**Quote-route SHADOWING split (verify before editing a `/api/quote/*` handler):** `main.py` includes **dashboard FIRST** (1069) then **quotes.py** (1076), so **dashboard.py serves `/api/quote/save` + `/update` + `/rates`** (the quotes.py copies are DEAD, commented out) while **quotes.py serves `/api/quote/accept_to_job` + `/list` + `/get`**. Quote server-math lives in **dashboard.py**: `_calc_quote_total`, `_replace_quote_line` (sibling-preserving in-place), `QUOTE_PRODUCT_IN_OUT=141` / `QUOTE_PRODUCT_OUTSIDE=103`, `QUOTE_DIFFICULTY`, `_quote_breakdown_text` (the note line + a `QUOTE_JSON_TAG` blob for round-trip), `_quote_service_label` (product display_name).

**★ TWO branded-page gotchas (apply to BOTH the invoice page `api_job_print_invoice` AND quote_view):**
1. **The business PHONE on the page is `res.company` id=1 `phone` (Odoo DATA), NOT a code hardcode.** It renders via `_co.get('phone')`. If it shows the wrong number (DJ's cell `9519726946` was on it until 2026-10-26), the fix is to **update the company record** (one field → `7603345355`), which corrects invoice + quote + everywhere at once. ⚠ The `951-972-6946` strings in dashboard.py / portal.py are only **docstring EXAMPLES** in phone-matching helpers — editing them does NOTHING. res.company write is a shared-resource/outward-facing change → goes through **Operator + DJ one-tap OK**, not a raw peer write (my raw write was correctly classifier-blocked).
2. **Page dates MUST render in Pacific.** Use `datetime.datetime.now(_PT).date()` (`_PT = ZoneInfo('America/Los_Angeles')`, dashboard.py:11), NOT `datetime.date.today()` — the Render box is UTC, so `date.today()` prints TOMORROW after ~5pm PT. Fixed on the invoice "Date issued" 2026-10-26 (main `20059398`); the quote page was built PT from the start.
