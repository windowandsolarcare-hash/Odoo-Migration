**DJ (2026-09-12), on discovering the endpoint map had been built then forgotten:** the fleet mapped every route (Audit's `3_Documentation/ENDPOINT_MAP.md`) specifically so sessions would stop re-reading code and get to solutions faster — and then it was "filed and set aside." A session (Lead) reasoned an endpoint problem from scratch instead of opening the map. DJ: *"it needs to become much more important... make it important."*

**The map:** `3_Documentation/ENDPOINT_MAP.md` in `windowandsolarcare-hash/saunders-render-app` — auto-generated by `3_Documentation/gen_endpoint_map.py` (AST sweep of main.py + routers). Canonical list of EVERY HTTP route: method, full path, **LIVE-vs-DEAD shadow** (which handler wins under FastAPI include-order), file:line, what-it-does, auth. As of 2026-09-12: ~852 routes / 755 live / ~97 dead.

**How to apply:**
- **Endpoint lookup = map first, code second.** Before grepping/reading router code to find or verify a route — for BUILDING, REVIEW/QC, or ANSWERING DJ — open ENDPOINT_MAP.md. Only fall back to grep when the map is missing a very-recent route (then regenerate it).
- **Use the LIVE column to avoid the shadow trap** (editing a DEAD twin = zero production effect; burned sessions on `/owner/ask`, `/api/hemet/*`).
- **Keep it CURRENT — a stale map that looks authoritative is its own trap.** It silently drifted 8 days once (2026-09-04 → 09-12) because the "regenerate on ship" step was skipped, so a whole night of route-adding work (Thumbtack flow, Cheryl assistant) went unmapped. Two guards now: (1) **CLAUDE.md pre-push gate 3** — the shipping session regenerates (`python 3_Documentation/gen_endpoint_map.py <root>`) and pushes the map WITH any route add/change/rename/remove; (2) **Audit's hourly tick** re-runs the generator as an automatic backstop (pushes only on change). Primary is the push-gate; Audit is the safety net.

**The bigger lesson (why this memory exists):** AI tunnel-visions on the task and forgets capabilities the fleet already built. An inventory only pays off if it's LOADED into the routine and kept fresh — building it isn't enough. Same principle as a broader "capability inventory" the fleet should maintain.
