**Phase 2 shipped 2026-08-17 (decaying dashboard — the "not an inbox" part):**
- Blob grew: `{msgs, cards, proposals, proposed_through}`. **Card** = `{id,title,summary,action_items:[{text,done}],state,heat,created_at,last_touch_at,promoted_by}`; state ∈ `spark|shaping|moving|done|parked` (active = spark/shaping/moving). **Proposal** = `{id,title,summary,action_items:[str],at}`. `proposed_through` = watermark = last msg id Claude has scanned for ideas.
- **Heat/decay:** base heat decays by half every **5 quiet days** (`_HALF_LIFE_DAYS`); any interaction `_touch()`es a card (+12 heat, refresh last_touch). Board ranks by EFFECTIVE (decayed) heat. A card idle **≥4 days** (`_STALE_DAYS`) while still active is flagged `stale` → rises as a nudge ("gone quiet — commit/park/kill?"). Computed at read time, no cron.
- **New endpoints:** `GET /api/ideas/board` (cheap, no LLM — returns active[] ranked + resolved[] + proposals[] + nudge_count + unscanned count), `POST /api/ideas/propose` (scans msgs since watermark, Claude extracts DISTINCT ideas as proposals, dedupes vs existing card/proposal titles, advances watermark; best-effort), `POST /api/ideas/promote {proposal_id|title,by}` (proposal→Spark card at heat 100; Dan or Cheryl), `POST /api/ideas/proposal_dismiss {proposal_id}`, `POST /api/ideas/card_update {id, state|title|summary|add_item|toggle_item|edit_item|del_item}` (every edit bumps heat), `POST /api/ideas/card_delete {id}`.
- **ideas.html** gained a **Board view** (Chat/Board tab toggle in header; badge on Board tab = proposals+nudges). Board shows: New-idea + Scan buttons, "Claude spotted these" proposal tray (Promote/Dismiss), "Needs a decision" nudge section, "Active" cards (heat pip + state <select> + action-item checkboxes + inline note edit + Park/Done/Kill), collapsed "Done/Parked". Auto-scans once on Board open if unscanned>0.
- **★ Concurrency caveat:** the single `ir.config_parameter` blob is load-modify-save with NO locking. RAPID successive writes (my Phase-2 smoke test fired many in ~1s) can clobber each other (lost updates) — one dismiss was lost. FINE at human tapping speed (same as the Library). Do NOT hammer it in tests; space writes out. When testing on the live blob, remember **DJ actively uses this** — preserve `msgs`, only clean your own test cards/proposals (I reset proposals+watermark via direct Odoo set_param on 2026-08-17 after a test scanned DJ's real messages).
