### VAPID KEY GOTCHA (verified 2026-06-16) — see [[reference_vapid_webpush_keys]]
`Vapid01.from_pem(pem_bytes)` works; `Vapid01.from_string(pem_str)` FAILS (treats input as DER/raw, ASN.1 error). pywebpush `webpush()` with a PEM **string** would hit from_string → fail. FIX: build `Vapid01.from_pem(base64.b64decode(VAPID_PRIVATE_KEY_B64))` once and pass the **Vapid instance** to `webpush(vapid_private_key=<instance>)` (pywebpush does `isinstance(...,Vapid01)`). Stored: `VAPID_PUBLIC_KEY` (b64url uncompressed point, 87 chars — browser applicationServerKey), `VAPID_PRIVATE_KEY_B64` (base64 of PKCS8 PEM, env-safe single line), claims sub hardcoded `mailto:windowandsolarcare@gmail.com`.
