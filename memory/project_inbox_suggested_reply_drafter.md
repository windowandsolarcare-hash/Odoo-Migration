The inbox "💬 Suggested reply" button (v2_inbox.html / inbox.html, `conv.draft`) is generated by **`_draft_reply()` in `routers/owner/sms.py`** on every inbound customer text (`sms_incoming`), unless the message was auto-handled (YES/STOP/reminder reply → draft skipped). There is ONE draft path — the `/api/inbox/thread` endpoint (~L522) only returns customer context, it does not draft.

**Fixed 2026-07-31 (Kevin Armintrout case).** Kevin asked "I'll mail a check, how much do I owe you?" for panels Dan had already cleaned that day. The suggestion invented "$125", called the done cleaning "upcoming (7/31)", and used corporate voice ("Hi Kevin! Thanks for reaching out… -WSC"). **Root cause: `_draft_reply` was only given the single latest inbound text + the 3-job list — never the conversation — so it guessed.** (It even had `amount_total` in `_customer_context` and still fabricated a different number → the real lesson is the model must be forbidden from stating any number it isn't given.)

**The fix (surgical, additions only):**
- Added **`_thread_text(conv, limit=10)`** — builds a plain `Dan:/Customer:` transcript from `conv['msgs']` (`dir=='out'`→Dan, else Customer), oldest-first.
- `_draft_reply(customer_name, message, context, thread='')` now takes the thread; call site passes `_thread_text(conv, limit=10)`.
- System prompt rewritten: **Dan Saunders' own voice** (warm, first-name, short, no emoji/hashtags, no "Hi X! Thanks for reaching out", no "WSC" sign-off — sign "- Dan" if any); **answer only what was asked, no upsells**; **CRITICAL never invent a price/amount/date/address** not present in the data — if asked what they owe with no exact total given, use a **`[total]` placeholder**, never guess.

Takes effect on the NEXT inbound text (drafts are computed at receive time and stored in `conv['draft']`; existing stored drafts do not retro-update).

**Why:** an AI reply that states a wrong dollar amount to a customer is a real money/trust error — the no-invent rule is the important part; the thread context is what makes it actually answer the question. **How to apply:** any customer-facing AI draft must (a) see the conversation, not just the last line, and (b) be forbidden from stating facts (esp. prices) it wasn't given. sms.py is the specialists session's file — this fix was mailed to them (AGENT_MAIL 2026-07-31).
