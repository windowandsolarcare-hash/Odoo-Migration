The company name is **Window & Solar Care** (with ampersand, no leading "A").

**Why:** The project folder is named "A Window and Solar Care" — that "A" is just a filing convention to sort it alphabetically, not part of the brand. Using "A Window and Solar Care" in customer-facing content is wrong.

**How to apply:** In all customer-facing text (job postings, emails, documents, signatures), always write "Window & Solar Care" — never "A Window and Solar Care." The [[DJ User Profile]] memory confirms this.
