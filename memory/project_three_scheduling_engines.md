**Three engines that independently decide availability** (they share only the slot-grid primitives in `routers/booking.py`: `_all_slots`, `SLOT_MIN`, `AM_CUTOFF_MIN=720`, `WORK_END_MIN=1020`, `_slot_label`):

- **A — `routers/owner/scheduler.build_day_plan`** (the canonical "shared scheduler brain"). Busy = firm sale/done **+ held reserves** (`held_intervals_for_day`: draft/sent maint + pending slot offers) **+ extra_busy**. Applies the **drive pad** via `_reachable` (flat `DESERT_DRIVE_MIN=20 + SLOT_BUFFER_MIN=15`). Coords **healed** via `prop_geo` (bbox-guarded). Returns `{schedule, slots[{minute,label,half,suggested}], suggested_minute}` — `slots` is ONLY the reachable grid starts. Used by the review screen, command center/regen, new_job, submitted_jobs.
- **B — `routers/booking._open_dates_for_city`** (public /book + /dw landing "morning/afternoon free"). Per candidate day: `free = _free_slots_dur(_intervals)` where `_intervals` (from `_jobs_by_day_geo`) = firm jobs + held reserves; then `am_free = any(s<720)`, `pm_free = any(s>=720)`. **NO drive pad** → it marks a half free on a pure time-gap, so it OVER-OFFERS halves A then rejects. (This is the "two scheduling engines" mismatch Web flagged.)
- **C — `routers/owner/dashboard._find_scheduling_openings`** (the AI `find_next_opening` voice tool; the `field.py` twin at :2373 is DEAD — dashboard shadows it). Returns a **TEXT** answer (ranked days + ONE suggested `slot_time`), **no am/pm concept**. Busy = `state in sale/done` + `workiz_status not in [Done,Canceled,Postponed]` — **EXCLUDES held reserves**. **NO drive pad** (distance is ranking-only). **RAW** `partner_latitude/longitude` (no `prop_geo` heal → bad-pin risk). Free-form gaps (not the fixed grid), workday 8:30–15:00, 14-day lookahead. **3rd hardcoded copy of `CITY_SCHEDULE`** (scheduler.CITY_WEEKDAYS and booking.CITY_SCHEDULE are the other two). Consequence: the AI can propose a time that's already held/offered or unreachable.

**Why it matters / how to apply:** when "landing says a half is free but the review screen says no open slots" (or "the AI suggested a taken time"), it's almost always the **drive pad + held-reserve** difference between these engines, not a slot-finder bug — check WHICH engine produced the answer.
