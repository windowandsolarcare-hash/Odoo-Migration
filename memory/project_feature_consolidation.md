**DJ's north-star for fighting feature sprawl (2026-07-13):** the app keeps growing (home screen = ~10 groups, 30+ tiles). DJ wants to CONSOLIDATE into **6 buckets**, each ideally a single "front door" that **lists choices (logic, not icons) and routes to the correct existing path** — like the New Order front door ([[project_new_order_frontdoor]]). Roll in / eliminate duplicate logic where possible.

**The 6 buckets:** 1) **Orders** (input/edit/view/delete) — DJ considers DONE (New Order front door). 2) **Inputs** (My Day tasks, Vault, notes, planner…). 3) **Output** (reports, analysis). 4) **CRM**. 5) **AI**. 6) **Third-party tools**.

**Inputs front door — BUILT 2026-07-13** (commits inputs.html b4e6c2d, myday.py 5276307, index.html 241d8ea): new page **`/owner/inputs`** (`static/owner/inputs.html`, route in myday.py `inputs_page`) = a choice list that routes: 📝 Task/reminder→/owner/myday · 👤 Note about a customer→/owner/field?tab=customers · 🗄️ Note/document→/owner/vault · 🗓 Plan my day/habits→/owner/planner · 🔍 Find→/owner/vault. **Extensible:** add one line to the `CHOICES` array. Home menu: the "My Day" group (My Day + Vault + Daily Planner tiles) collapsed to ONE **📥 Inputs** tile → /owner/inputs; those pages still reachable directly + via cockpit My Day quick-link. **Activities tile HIDDEN** per DJ (removed from Schedule group; route `/owner/activities` kept live as fallback — My Day supersedes it, was already 1/2 deprecated [[project_activities_module]]). DJ: add "customer notes" (done) + "other things later" (that's why it's a config array).

**★ Inputs = SMART COMMAND BAR (2026-07-13, commits myday.py 7f5539d / inputs.html 3c8a3d6 / myday.html cf782ca):** DJ rejected the icon list AND a plain box ("box gives up My Day's important fields") AND a dropdown ("too simple") — wanted "creative/cool/unique." Chosen concept: **command bar** — type/say plainly → **`POST /owner/api/capture`** (myday.py; Claude CLAUDE_HAIKU classifies into task|customer_note|document|plan|search|unclear + extracts title/due/customer/note/query + summary; due words→ISO via today_pt) → returns a tappable **chip** `{icon, summary, label, href}` → tap opens the CORRECT full form **pre-filled** (the box ROUTES, never replaces the rich forms). inputs.html = the bar (debounced 650ms oninput → capture → chip) + verb-chip fallback. TASK href = **`/owner/myday?add=1&title=&due=`** → myday.html `handleDeepLink` calls `openSheet()` (the FULL task editor tkName/tkDate/priority/recur/tags) + prefills tkName/tkDate, then strips the URL params. customer_note→field?tab=customers&cust_q=&prefill_note= (field.html doesn't consume prefill_note yet — TODO). ⚠ myday.py needed local `import urllib.parse` (shared __all__ excludes stdlib: os/json/urllib NOT exported — json already imported at top; get_anthropic_client/CLAUDE_HAIKU/ODOO_USER_ID/today_pt/odoo_rpc ARE exported).

**★ AI classification is a GUESS — always ship the override (2026-07-15, commits inputs.html 414278f / myday.py f79e56d):** DJ hit a real miss — he typed something he wanted as a TASK and Claude routed it to `customer_note`. The chip only ever offered ONE route, and the blank "…or just pick a type" fallback links at the bottom carried **no text**, so a wrong guess meant retyping the whole thing. Fix: `/owner/api/capture` now builds the deep-link for EVERY type via a local `_mk(t)` helper (each carrying the same extracted `title/note/customer/query/text` + `_due_iso`) and returns the losers as **`alts: [{type,icon,label,href}]`**; `unclear` returns all five. inputs.html `altRow(alts, lbl)` renders them under the chip as "Not that? Send it here instead —". **Design principle DJ wants: don't add an approval step that taxes the happy path — make the wrong answer cheap to correct (one tap, text preserved).** Applies to any AI-classifies-then-acts flow. NOTE the capture bar only ROUTES (never commits), so a mis-pick costs zero data — the cost was purely the retype. Contrast [[project_saunders_vault_notes]] notes.py, which classifies AND commits in one POST with no override and no folder-move endpoint — a misfiled note stays misfiled (still open).

**⚠ Known gap:** `field.html` still doesn't consume `prefill_note` — so choosing the 👤 Customer note route (chip OR alt) lands on the customer tab without the note text pre-filled. Task/plan/search/document routes are fine.

**Consolidation rationale confirmed this session:** Activities ≈ My Day (same project.task+mail.activity data, two UIs — My Day is canonical); Daily Planner ↔ My Day are two-way synced [[project_planner_myday_sync]]; Vault is distinct (docs) but same front door. **Next buckets to tackle (DJ's order): Inputs done → likely Output/CRM next.**
