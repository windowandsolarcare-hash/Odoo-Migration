**★ AI DRAFT — context-aware re-engagement (BUILT 2026-06-27, DJ's vision).** DJ's real method = read the customer's last text, reference it, continue the conversation (not out-of-the-blue). TWO MODES (AI judges from the thread, DJ 2026-06-27): **MODE A CONTINUE** — when the recent thread shows DJ already asked about cleaning and they DEFERRED ("on vacation, get back to you" / "call me later" / "next month") → SHORT, DIRECT, reference their last line, straight to scheduling, **NO pitch** (no desert-dust/dulls-view/easy-to-let-slide — they already know). **MODE B BREAK-THE-ICE** — cold/old thread, no recent cleaning talk → the warmer ice-breaker with ONE light reason (dust dulls view / panels lose output).
