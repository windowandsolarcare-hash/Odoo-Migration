DJ set this 2026-09-28. When Design works with **Cheryl** on a card:

- **Cheryl owns the IMAGE.** She works out / generates the hero image in Midjourney and gets Design the downloaded file. Design does NOT need to run Midjourney for her cards (and can't drive her logged-in MJ from the controlled browser anyway — see [[feedback_render_design_before_presenting]] workflow notes).
- **Design owns EVERYTHING ELSE — the text lives OUTSIDE Midjourney, on the canvas/artifact.** Design's job:
  1. **Write the COPY for the FRONT and the BACK** of the card (headline/offer/message + back content). Never let Midjourney render text/logo/phone — all type goes on the canvas as real type.
  2. **Insert Cheryl's downloaded image** as the hero, lay out both sides on the design canvas.
  3. Build to exact print spec; if it's mailed EDDM, apply [[project_eddm_mailing_rules]] (size, address-top-half, indicia) + [[project_wsc_print_build_pipeline]].
  4. **Present a PROOF to Cheryl** — the RENDERED card WITH trim + safe (+ EDDM) guide lines, as an image she can see — in plain, non-technical language ([[feedback_render_design_before_presenting]], [[feedback_design_end_to_end_workflow]]).
- **One stable link**, edit by conversation, iterate to the SAME artifact URL. Cheryl is non-technical — never make her learn a tool; talking to Design IS the interface.

**Why:** DJ split the labor so Cheryl only does the fun/creative image part in a tool she knows, and Design carries the copywriting + layout + print-spec + proofing — which is where the mistakes (EDDM rules, trim, legibility) actually happen.

**How to apply:** To START a specific Cheryl card, get from her/DJ just: (a) the downloaded MJ image, (b) one plain sentence on what the card is for + which business it's for (likely Cheryl Johnson REALTOR®, company 2), and (c) her contact/brand details to set on the card (phone, DRE#, etc.). Then Design drafts front + back copy, builds both artboards, and presents both proofs. Front and back are BOTH Design's deliverable — never just the front.
