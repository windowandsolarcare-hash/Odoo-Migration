**Data model:**
- Employee core = Odoo **hr.employee** (name, job_title, employee_type, work_email, work_phone, mobile_phone, private_phone, **emergency_phone**, **x_render_access_code**=app PIN, company_id=1). Existing emps: Dan Saunders(id1), Danny Saunders(id2 Field Tech). Payroll = **Gusto** (x_gusto_* fields exist).
- HR extras (start_date, pay_type, pay_rate, status, notes, **onboarding checklist**) = `ir.config_parameter` key `hr.employee.extra.{id}` JSON. Onboarding seeded from ONBOARDING_TEMPLATE (10 steps) per new hire; each item {label,done,at,by}.
- **Documents** = `ir.attachment` res_model='hr.employee', res_id=emp_id, description=doc_type. Served by GET /owner/api/hr/document_file?att_id= (guards res_model).
- **HR tasks** = dedicated JSON list in `ir.config_parameter` key `hr.tasks` = [{id,title,assignee(DJ/Cheryl),due,priority,emp_id,notes,done}]. NOT yet project.task/My Day — editor MIRRORS My Day's (sheet w/ title/assignee/due/priority/notes). TODO if DJ wants: bridge HR tasks → project.task so they surface in My Day.

**Endpoints (all /owner/api/hr/*):** employees, employee?id=, employee(POST save), onboarding(POST toggle), documents, document(POST upload b64), document_delete, document_file(GET serve), tasks, task(POST save), task_done, task_delete.
